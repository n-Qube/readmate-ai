One product · six bounded tools

Useful enough for a real reading workflow.

Read-only tools act immediately. Saving, subscribing, and generating study material open visible forms so the user reviews the details before anything changes.

readmate_search_library

Search the library

Find saved reading by title or metadata without exposing full document text.

readmate_get_document_context

Confirm the document

Read compact metadata and learning availability for one owned item.

readmate_prepare_listening

Prepare listening

Set up English, Twi, Ewe, or Ga playback. It never starts audio or spends speech quota.

readmate_add_web_page

Save a webpage

Fill a review form for one public HTTPS page; the user makes the final submission.

readmate_subscribe_rss

Subscribe to a feed

Prepare a public RSS or Atom subscription while keeping the change visible.

readmate_generate_study_pack

Generate a study pack

Prepare summaries, flashcards, or quizzes only after the user confirms the paid AI action.
